# Storm Lightning для Owlbear Rodeo

Простое расширение для Owlbear Rodeo 2, которое добавляет атмосферные молнии поверх сцены.

Молния состоит из короткой цветной вспышки и процедурного разряда. Эффект синхронизируется между игроками, поэтому все участники комнаты видят одну и ту же грозу.

## Возможности

- ручной запуск молнии;
- автоматическая гроза со случайным интервалом;
- настройка цвета вспышки и разряда;
- настройка яркости;
- минимальная и максимальная пауза между молниями;
- отображение самого разряда можно отключить;
- режим двойной вспышки;
- синхронизация эффекта между игроками.

## Как использовать
Создайте page на cloudflare.

Добавьте URL `manifest.json` расширения в Owlbear Rodeo через меню **Extensions / Add Custom Extension**.

После подключения откройте **Storm Lightning** в комнате Owlbear.

Кнопка **«⚡ Молния сейчас»** запускает одиночный разряд.

Кнопка **«Запустить грозу»** включает автоматические молнии. Интервал между ними случайно выбирается между значениями «Минимальная пауза» и «Максимальная пауза».

Кнопка **«Остановить»** выключает автоматическую грозу.

Цвет влияет как на вспышку сцены, так и на сам разряд. Для обычной молнии хорошо подходит белый или холодный голубой цвет, но можно использовать красный, зелёный и любые другие варианты.

## Важно

Управление грозой предназначено для ведущего. Игроки получают синхронизированный визуальный эффект автоматически.

Расширение не изменяет карту и не создаёт постоянные объекты на сцене — молнии существуют только как временный визуальный эффект.
